# CLIP hidden states 可解释性调研及其对视频异常检测的启发

更新时间：2026-08-25

## 1. 调研问题

本文围绕三个问题展开：

1. 现有 CLIP 可解释性工作把什么当作“神经元”或功能单元？
2. 它们怎样使用中间 hidden states：逐维分析、多层拼接、训练探针、概念分解还是因果干预？
3. 在我们已有全层 CLS hidden states、只有视频级弱标签、需要适配三个 baseline、单卡 4090 的条件下，下一步应采用什么方案？

已有实验事实也作为方法约束：DANCE 在不依赖 baseline 分数的情况下能够从 hidden states 中读出异常类别语义，但将这些维度注入 DSANet 后没有提升时序定位指标。这说明“含有异常语义”不等于“能够定位异常片段”，也不等于 baseline 会使用这些信息。

## 2. 文献中的五种 hidden states 用法

| 路线 | 典型方法 | hidden states 的用法 | 能回答的问题 | 主要局限 |
|---|---|---|---|---|
| 单元描述 | CLIP-Dissect | 为单个通道寻找高激活样本，再用 CLIP 文本概念给通道命名 | 一个通道与哪些概念相关 | 相关性描述，不证明该通道被模型用于决策 |
| 逐层探针 | linear probing、layer-wise probing | 冻结 backbone，在每层 CLS 上训练低容量分类器 | 某层能否线性读出目标信息 | 探针可能自己学会任务；可解码不等于模型在使用 |
| 多层融合 | concat、learned weighting、ALF | 拼接或注意力融合多层 CLS/patch summary | 哪些层对下游任务互补 | 直接拼接维度大、方差高，弱标签下容易学到场景捷径 |
| 概念基分解 | SpLiCE、SAE、Matryoshka SAE | 将稠密向量表示成少量可命名概念方向 | 哪些概念方向组成当前表示 | 字典依赖强；SAE 训练和验证成本较高，仍可能存在多义与分布外失效 |
| 机制与因果路径 | TextSpan、second-order lens、ablation | 分解层、注意力头、MLP 神经元到最终输出的贡献，并做删除/干预 | 哪些内部路径真正改变模型输出 | 需要更细粒度的内部激活或重新前向，不能仅靠缓存 CLS 完成完整机制分析 |

### 2.1 单维度描述：可以解释，但不适合作为最终功能单元

CLIP-Dissect 利用神经元的高激活图像和候选文本概念之间的 CLIP 相似度，为隐藏通道生成自然语言描述。它适合建立“某个维度可能响应什么”的图谱，但本质仍是相关性分析，并不说明该维度对最终预测具有因果作用。[CLIP-Dissect, ICLR 2023](https://arxiv.org/abs/2204.10965)

更直接的 CLIP 机制研究表明，把残差流中的单个坐标当作独立、单义神经元并不稳妥。Second-order Lens 将真正的 MLP 神经元定义为 MLP 非线性后的激活，并发现其直接残差贡献和简单整体消融都难以揭示功能；有效影响经由后续注意力头传播，而且单元普遍具有多义性。[Interpreting the Second-Order Effects of Neurons in CLIP, ICLR 2025](https://arxiv.org/abs/2406.04341)

因此，我们缓存的 `layer × 768` CLS 坐标仍可作为最细的归因单位，但不应再声称每个坐标就是一个独立的机制神经元。更准确的对象应是“跨层功能子空间”，单维度只用于把该子空间的贡献向原坐标回溯和可视化。

### 2.2 多层探针：逐层线性探针用于诊断，注意力融合用于适配

逐层线性探针的常见做法是冻结 CLIP，对每一层的 CLS 单独归一化并训练相同容量的线性分类器。它能画出任务信息随层深的变化，但不能证明 CLIP 或 baseline 原本依赖这些信息。探针研究已经反复指出：探针容量、控制任务和选择性必须一起报告，否则高准确率可能来自探针自身的记忆或拟合。[Designing and Interpreting Probes with Control Tasks, EMNLP 2019](https://aclanthology.org/D19-1275/)

多层融合通常有三种形式：

1. 直接拼接所有层，再训练线性层；
2. 为每层学习一个标量权重，再加权求和；
3. 将每层表示投影到共享低维空间，用可学习查询对层序列做注意力融合。

2026 年的 Attentive Layer Fusion 在多个 ViT 和 CLIP 模型上比较了这些形式。结果支持“任务相关信息分布在不同层”，同时指出直接拼接虽然有时有效，但训练方差和不稳定性更高；任务自适应的注意力融合更可靠，而且只处理十余个层 token，开销远小于 patch attention。[Attentive Multilayer Fusion for Vision Transformers, 2026 preprint](https://arxiv.org/abs/2601.09322)

需要保留反证：多层拼接并非对所有预训练目标都有效。已有表示分析发现，联合嵌入型模型的类别语义往往更集中在后层，中间层拼接的边际收益可能较小。因此“使用全部层”应当作为可学习候选，而不能预设每层都有效。[Objectives Matter, 2023](https://arxiv.org/abs/2304.13089)

对我们的启发是：不再根据一次统计结果硬选第 8、12 层，也不把 12×768 直接拼到 baseline。应先让一个小型层注意力模块从所有层中学习，再用稀疏约束和消融结果将其剪枝到 2–4 个真正有效的层。

### 2.3 稀疏概念方向：比原始坐标更适合作为“可解释单元”

SpLiCE 不解释原始单维度，而是用大量短文本概念构成字典，将 CLIP 稠密向量分解成少量非负概念系数。它还处理图文模态均值偏移，并证明稀疏概念表示可以保留相当一部分下游线性探针能力，也能通过概念删除干预偏差。[SpLiCE, NeurIPS 2024](https://arxiv.org/abs/2402.10376)

Sparse Autoencoder 路线则从数据中学习过完备稀疏字典。层级 SAE 可以得到由粗到细的嵌套概念；PatchSAE 还将 CLIP 中间残差流的 CLS 与 patch token 一起重构，并用消融/重构测试概念是否影响输出。[Matryoshka SAEs, ICML 2025](https://arxiv.org/abs/2502.20578)；[Sparse Autoencoders Reveal Selective Remapping, 2024 preprint](https://arxiv.org/abs/2412.05276)

但是，大型 SAE 常把 768 维扩展到数万 latent，需要大量训练样本、显存和稳定性验证。更重要的是，SAE 的稀疏性本身不能保证组合泛化和因果忠实性。对当前单卡约束，先采用 64 或 128 维的低秩概念子空间，再通过文本命名和因果删除验证，比直接训练 49,152 维 SAE 更合适。

### 2.4 CLIP 机制分解：功能通常存在于路径和子空间，而非一个坐标

TextSpan 将最终 CLIP 图像表示分解到 patch、层和注意力头，并用文本方向描述注意力头子空间。研究发现最终输出主要由后部若干层的注意力头直接构成，不同头可负责位置、形状、颜色、计数、OCR 等属性；移除伪相关头还能改善群体鲁棒性。[Interpreting CLIP's Image Representation via Text-Based Decomposition, ICLR 2024](https://arxiv.org/abs/2310.05916)

这与 Second-order Lens 的结论一致：有行为意义的单位通常是“上游激活—后续注意力头—输出方向”的路径。我们当前只有逐层 CLS，无法完整还原注意力头和 MLP 路径，但可以退一步学习跨层低秩子空间，并用删除该子空间后 baseline 输出和 AUC/AP 是否下降作为因果验证。

### 2.5 异常检测工作：结构偏离与异常语义应当分开

LAKE 是与“异常敏感神经元”最接近的工作。它使用少量正常图像，根据正常 patch 特征的通道统计挑选稀疏维度，建立正常图库得到结构偏离分数，再用更深层 patch 特征与正常/异常文本对齐得到语义分数。[LAKE, 2026 preprint](https://arxiv.org/abs/2604.07802)

它对我们的真正启发不是照搬“Top-K 通道”，而是将两种证据分工：正常参考负责发现“是否偏离正常”，文本负责验证“偏离是否具有异常语义”。LAKE 的优势依赖 patch 局部结构和正常图库，其边际方差选维也隐含坐标相对解耦的假设，不能直接迁移到视频 CLS。我们的 DANCE 中两个类别维度并集超过 1200，正好说明视频 CLS 异常证据更分散。

图像异常检测中的 AnomalyCLIP、AA-CLIP 等工作进一步说明，原始 CLIP 的普通类别文本并不天然形成可靠的正常/异常边界。它们通常学习对象无关的正常/异常 prompt 或异常感知文本锚点，并用适配器对齐多层视觉特征，而不是直接使用固定的 `normal`/类别名称。[AnomalyCLIP, ICLR 2024](https://arxiv.org/abs/2310.18961)；[AA-CLIP, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Ma_AA-CLIP_Enhancing_Zero-Shot_Anomaly_Detection_via_Anomaly-Aware_CLIP_CVPR_2025_paper.html)

针对视频异常检测的 Alert-CLIP 更直接地观察到：CLIP 文本空间中的正常与异常描述高度纠缠，视频对两类 prompt 的相似度也接近。它通过视频—标签、异常区域—详细文本、异常区域—困难负例三层对齐重塑异常感知空间。[Alert-CLIP, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Zhu_Alert-CLIP_Abnormality-aware_Latent-Enhanced_Representation_Tuning_of_CLIP_for_Video_Anomaly_CVPR_2026_paper.html)

这正好解释我们的已有实验：固定文本梯度能够读出“打架/爆炸等类别语义”，却没有学会“这个片段相对于当前视频的正常上下文发生了异常”。把类别相关维度直接增强，容易持续增强场景、人物和物体语义，反而污染边界定位。

## 3. 对现有方案的诊断

### 3.1 目前探测到的到底是什么

当前方法探测到的是“与视频标签和固定异常文本方向相关的 CLS 坐标”，而不是已经验证的异常责任神经元。它具备三层含义：

1. 表示层：该坐标携带某些异常类别可解码信息；
2. 相关层：该坐标在异常视频或文本梯度中表现出较强相关性；
3. 尚未证明的机制层：baseline 是否依赖它、改变它是否改善片段定位。

DANCE 已经证明前两层，但 DSANet 退化说明第三层不成立或至少不充分。

### 3.2 为什么简单多层拼接大概率仍然不够

直接拼接可以增加可解码信息，却同时放大三个问题：

- 视频级标签被复制到所有 snippet，探针容易学习场景和视频身份；
- 12×768 的输入使小样本弱监督更容易过拟合；
- 拼接只告诉模型“还有哪些信息”，没有规定“结构偏离”和“异常语义”各自负责什么。

所以拼接应只作为消融基线，不能作为主方法。

### 3.3 为什么只训练一个异常线性探针也不够

线性探针适合回答“哪层能读出异常标签”，但视频级 MIL 探针仍可能依赖整段视频的背景分布。必须配合随机标签、随机同秩子空间、时间打乱、正常视频内部切分和子空间删除等控制实验。只有删除所选子空间显著降低模型异常响应，而删除随机同维子空间没有同等影响，才能把“可解码”提升为较可信的“功能责任”。

## 4. 推荐方案：跨层异常概念子空间，而不是逐维神经元注入

建议将下一版方法定义为 **Cross-layer Anomaly Concept Circuit（CACC）**。核心不是增加更多 hidden dimensions，而是从全层 CLS 中学习一个低秩、可命名、可干预的功能子空间，并将“正常偏离”与“异常语义”解耦。

### 4.1 输入与层融合

对每个 snippet 的 12 层 CLS 分别使用正常训练视频统计量做 LayerNorm 或标准化：

`h_l -> P_l(h_l) in R^64, l=1,...,12`

每层使用独立的 `768 -> 64` 低秩投影，再用一个可学习 query 对 12 个 layer token 做注意力融合。增加 group-lasso 或稀疏层门控，使有效层自然收缩；训练结束后依据稳定门控和因果消融剪枝到 2–4 层。第 8、12 层只作为已有实验先验，不再硬编码。

该模块约有 `12 × 768 × 64 = 589,824` 个主要投影参数，加上小型注意力仍远低于一个 baseline，单卡 4090 开销很小。现有全层 CLS 产物可直接复用，不需要 patch token。

### 4.2 双分支证据，而非单一异常分类探针

**分支 A：正常动力学/结构偏离。** 只使用正常训练视频，学习正常概念空间中的局部原型和短时上下文预测。片段分数由两部分组成：到正常原型的距离，以及当前概念表示相对前后上下文预测的创新量。它不依赖 baseline 分数，也不把异常视频中的所有片段当作异常。

**分支 B：异常感知语义验证。** 不使用固定类别名称直接提供伪标签，而是学习对象无关的 normal/abnormal 锚点，并加入容易混淆的正常行为作为困难负例。视频级标签只约束 bag 级语义边界；文本分支用于回答“这个偏离是否像异常”，不负责独立决定时间位置。

最终异常证据采用门控而非简单相加：

`e_t = deviation_t × sigmoid(semantic_margin_t)`

即语义只能在正常动力学已经显示偏离时放大分数。这样能够避免 DANCE 中类别语义贯穿整段视频、导致定位退化的问题。

### 4.3 与三个 baseline 的统一接口

CACC 输出固定维度的概念表示、偏离分数和语义门控，不访问任何 baseline 的预测分数。共享增强形式为：

`x'_t = x_t + gamma × deviation_t × semantic_gate_t × W_c c_t`

其中 `x_t` 是三个 baseline 原有的 512 维 CLIP 特征，`c_t` 是 64 维概念子空间，`W_c` 投影回 512 维。三个 baseline 共用同一模块、损失和超参数，只在 Stage B 按各作者网络结构解冻其原本最接近输出的部分；解冻范围可以不同，但选择原则必须一致。

### 4.4 解释性验证必须从“看权重”升级为三层证据

1. **可读出性**：逐层探针和融合探针能否读出视频标签；
2. **可命名性**：将 64 个概念方向与异常行为、正常行为、场景和物体词典匹配，识别真正行为概念和场景捷径；
3. **因果性**：删除 Top 概念子空间、随机同秩子空间、场景概念子空间，比较 snippet AUC/AP 和 baseline 输出变化。

只有同时满足“稳定出现、可命名、删除后有特异性性能变化”的方向，才称为异常责任概念。原始 `layer × dimension` 权重可继续展示，但作为概念方向的组成系数，而不是独立功能神经元。

## 5. 最小成本的先验验证顺序

在全面接入三个 baseline 前，先用现有 UCF CLS 产物完成四个冻结 CLIP 对照：

1. 最后一层 CLS + 线性 MIL 探针；
2. 12 层直接拼接 + 相同容量约束的线性探针；
3. 12 层标量加权 + 线性探针；
4. 12 层 `768 -> 64` 投影 + 注意力融合 + 双分支门控。

必须同时报告：参数量、训练方差、视频级识别、snippet AUC/AP、时间打乱、随机同秩子空间、Top 子空间删除。若第四项只提高视频级识别而不提高 snippet 定位，应停止接入 baseline；这能用较低成本提前证伪。

若第四项有效，再进行：

- Stage A：冻结 baseline，仅训练 CACC 和共享 512 维残差接口；
- Stage B：按各 baseline 作者的模型选择方式渐进解冻靠近输出的模块；
- 使用作者原始指标和 checkpoint 选择规则，保留作者权重作为零退化回退；
- 在 UCF 与 XD、三个 baseline 中保持 CACC 结构和默认超参数不变。

## 6. 最终判断

文献不支持继续把问题简化为“从 9216 个 CLS 坐标中找更多 Top-K 维度”。更有依据的方向是：

1. 用所有层作为候选，但通过低秩注意力学习层选择，而非直接拼接；
2. 把功能单元从单坐标升级为跨层稀疏概念子空间；
3. 用正常时序偏离负责定位，用学习得到的异常语义锚点负责验证；
4. 用子空间删除和随机同秩对照证明因果责任；
5. 最后才将经过验证的概念子空间以小门控残差接入并部分解冻 baseline。

这一方向比此前方案更有希望，因为它正面解决了已有实验暴露的两个根因：异常信息是分布式的，以及异常类别语义不等于片段级异常边界。但文献和当前结果都不能保证提升 2–3 个点，第一阶段的目的就是在较低开销下验证“跨层概念子空间 + 正常偏离门控”是否真正提高定位，再决定是否投入完整三 baseline 实验。
