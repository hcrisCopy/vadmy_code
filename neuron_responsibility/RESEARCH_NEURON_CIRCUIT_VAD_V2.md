# 从“神经元探测”到“异常证据通路学习”

## 结论先行

当前真正值得继续的方向，不是再设计一个更复杂的神经元分数，也不是把选中的维度拼接、残差注入或压成异常概率。前面的 DSANet/UCF 实验已经说明：选中神经元具有异常信号，但把该信号作为第二个弱检测器，会复制弱监督噪声，无法突破原 baseline。

更有希望的突破口是：将三个 baseline 统一看作“异常判别规则”，再增加一个位于 CLIP 表征和 baseline 之间的“异常证据通路模块”。该模块不预测哪个 snippet 异常，而是回答：当某个 snippet 被判为某类异常时，CLIP 内部哪些概念通路应当对这一判断负责？训练通过保留/抑制相应神经元后的反事实变化来学习责任，而不是用 baseline 分数生成伪标签。

建议的方法主线可概括为：

> 文本定义异常概念，神经元通路提供内部证据，反事实干预验证责任，baseline 负责时序决策。

暂称 **Concept-conditioned Neuron Circuit Routing（CNCR，概念条件神经元通路路由）**。

## 1. 三个 baseline 的结构共性与真正缺口

### 1.1 它们分别补了什么信息

| 方法 | 重点解决的问题 | 新增的判别依据 | 仍然没有回答的问题 |
|---|---|---|---|
| DSANet | 和什么正常模式比较 | 视频内正常原型、事件/背景语义解耦 | 当前片段究竟由哪些视觉内部证据支持为异常 |
| DeSC | 在什么时间行为下判断 | 瞬时敏感流与持续一致流 | 突变或持续响应是否来自异常本身，还是场景、运动和背景偏差 |
| LaGoVAD | 按什么异常定义判断 | 可变文本定义、视频文本映射 | 视觉表征内部哪些单元真正实现了该文本定义 |

这一概括与论文原始动机一致：[DSANet](https://arxiv.org/abs/2511.10334) 强调正常模式缺失和类别语义混淆；[DeSC](https://arxiv.org/abs/2603.19780) 强调瞬时异常与持续异常之间的敏感性—稳定性冲突；[LaGoVAD](https://proceedings.iclr.cc/paper_files/paper/2026/hash/f88bec15cc4cb56b432ee040bb63f94f-Abstract-Conference.html) 强调开放世界中异常定义会变化。

### 1.2 最新工作的共同趋势

近期视觉语言 WSVAD 工作主要沿以下方向补充信息：

- 加入更合适的正常参照或去偏机制；
- 加入多尺度时序、瞬时/持续角色或片段探索；
- 加入文本类别、属性、动态提示或双向视觉文本对齐；
- 对高置信片段、困难片段或噪声片段重新采样。

这些方法都在改善“比较对象、时间尺度和语义条件”，但大多仍把 CLIP 输出的 512 维向量作为不可分解的整体证据。后续模块知道要与什么比较、按什么时间尺度比较、按什么文本定义比较，却不知道这次相似度和异常分数由哪些内部功能单元产生。

这会留下三个共同问题：

1. **证据归因不充分**：相同的整体相似度可能来自真实异常动作，也可能来自火焰、夜景、人群、摄像机运动等共现背景。
2. **弱监督确认偏差**：用当前模型最高分片段继续监督模型，容易让早期偶然偏差不断自我强化。[UMIL](https://openaccess.thecvf.com/content/CVPR2023/html/Lv_Unbiased_Multiple_Instance_Learning_for_Weakly_Supervised_Video_Anomaly_Detection_CVPR_2023_paper.html) 已明确指出 MIL 容易偏向具有简单上下文的异常片段；[D²MIL](https://openaccess.thecvf.com/content/CVPR2026/html/Zhao_Learning_from_Noisy_Supervision_A_Denoising-Debiasing_Framework_for_Weakly_Supervised_CVPR_2026_paper.html) 也将异常视频中的正常 snippet 被错误赋予监督视为核心噪声。
3. **跨 baseline 的增量有限**：如果增强模块本身又输出一个异常分数，它与强 baseline 高度相关，只会形成第二个较弱检测器，融合上限受自身定位能力限制。

因此，论文问题不应写成“现有方法缺少神经元特征”，而应更精确地写成：

> 现有方法丰富了异常判别的外部条件，却没有约束视觉编码器内部证据如何支持片段级决策；在视频级监督下，模型因此可以利用任意与视频标签相关的内部通路完成 MIL 排序，而不必学习真正局部、概念一致且可迁移的异常证据。

## 2. 沈飞相关工作的共同研究逻辑

不能只借用 LAKE 的“稀疏神经元”表面形式。综合其近期神经元、伪造检测和安全对齐工作，更稳定的研究逻辑是四步：

1. **潜在能力假设**：预训练模型或已训练检测器内部已经包含任务知识，问题是知识没有被正确定位和调用。
2. **非均匀分布假设**：知识并非均匀存在于整个特征空间，而集中在少量关键层、神经元或通路中。
3. **因果干预验证**：不仅观察激活相关性，还通过增强、抑制、消融或替换检查输出是否按预期改变。
4. **定向唤醒或迁移**：只使用或更新这些功能单元，以减少无关语义、降低开销并保持跨域能力。

[LAKE](https://arxiv.org/abs/2604.07802) 将工业异常知识视为 VLM 中潜伏且稀疏的敏感神经元；[DNA](https://arxiv.org/abs/2601.22515) 先定位语义向局部伪造痕迹转变的关键层，再去除语义冗余、提取伪造单元；[V-FIND](https://arxiv.org/abs/2608.03008) 在视频伪造检测器中寻找稳定锚点神经元，并通过干预验证其功能特异性。其安全方向同样采用“定位共享神经元—干预验证—定向更新”的结构。

适配到 WSVAD 后，最有力量的动机不是“神经元比整体特征更细”，而是：

> CLIP 可能已经编码了打斗、枪击、爆炸、事故等异常概念，但粗粒度 MIL 没有足够约束把正确概念通路分配到正确时间位置。我们要解决的不是重新学习异常知识，而是学习在时间轴上可靠地调用和验证这些潜在知识。

这也解释了为什么以前的方法未奏效：以前完成了“找”，但没有完成“干预验证”和“定向唤醒”；选中的维度最后仍被当成外部附加特征或伪标签。

## 3. 前一轮实验到底证明了什么

DSANet/UCF 的文本责任实验得到：

| 项目 | AUC | AP |
|---|---:|---:|
| 作者 DSANet | 0.894446 | 0.374196 |
| 文本神经元 prior | 0.733183 | 0.154014 |
| 随机 64 维 | 0.671742 | 0.123436 |
| 联合训练最佳模型 | 0.894420 | 0.373876 |

这组结果同时说明两件事：

- 选中维度不是随机噪声：相对随机维度有约 0.061 AUC 的增量，探测方向包含可用信号。
- 该信号不适合作为绝对 snippet 标签：异常视频中 40.39% snippet 的 prior 大于等于 0.8，而低于等于 0.2 的比例仅 0.004%，造成大范围假阳性监督；训练越久正式 AUC 越低。

因此，失败的不是“神经元层面完全无信息”，而是错误地要求神经元 prior 完成 baseline 已经在做的片段检测任务。下一版应提供 baseline 原来没有的监督：**对内部证据的反事实约束**。

## 4. CNCR：概念条件神经元通路路由

### 4.1 神经元的定义不变，但研究对象从单维升级为通路

工程上仍将 CLIP ViT-B/16 每层 CLS hidden state 的一个维度定义为一个神经元，保持已有产物可复用。但方法不再声称单个维度天然等价于一个可读概念，而是把“层—维度—后续投影—文本方向”共同视为功能通路。

这样做是必要的。[CLIP 二阶神经元分析](https://arxiv.org/abs/2406.04341) 表明，仅看神经元对最终输出的直接或总体贡献可能无法捕获其功能；神经元还可能通过后续注意力产生选择性二阶效应，并表现出多义性。[CLIP-Dissect](https://openreview.net/pdf?id=iPWiwWHc1V) 也报告了概念与相关物体、纹理或背景混淆的失败模式。

### 4.2 阶段 A：不依赖 baseline 分数的概念通路发现

输入只使用已有 hidden states、CLIP 视觉投影、文本概念和视频级类别标签，不使用任何 baseline anomaly score。

对每个异常概念分别建立神经元责任，而不是先合成一个“异常”方向。责任分数至少包含：

1. 神经元激活变化与该类别文本相似度变化的一致性；
2. 在同类异常视频之间的稳定性；
3. 相对正常视频的区分性；
4. 相对其他异常类别的专属性；
5. 抑制该神经元组后，目标文本相似度下降而无关文本相似度尽量不变的干预效应。

采用粗到细策略：先选关键层，再在关键层内选稀疏神经元组。不能固定每层都取相同 top-k，否则会把大量冗余或无效中间层强行纳入。

### 4.3 阶段 B：构造反事实特征，而不是伪异常分数

对于片段特征构造三种视图：

- 原始视图 `x0`：作者 CLIP 特征；
- 通路增强视图 `x+`：只对选中神经元施加小幅可学习缩放；
- 通路抑制视图 `x-`：将同一神经元组向正常统计量收缩或进行均值替换。

模块只输出与原输入相同的 512 维特征，因此三个 baseline 的主体代码、输入接口和原始损失可以保持不变。已有 hidden state 直接复用；若先从最后一层开始，可通过冻结的 `ln_post + visual.proj` 重建 512 维特征，无需重新跑 CLIP 图像编码器。

### 4.4 阶段 C：责任排序，不做绝对定位

对异常视频，训练目标不是“责任高的 snippet 必须为异常”，而是：

- 若一个片段确实利用了类别 `c` 的证据，增强 `c` 通路后，其类别语义 logit 应提高；
- 抑制 `c` 通路后，该 logit 和异常证据应下降；
- 无关类别 logit 尽量保持不变；
- 正常视频上的增强/抑制不应引起大幅异常分数变化。

即约束相对顺序：`semantic_c(x+) > semantic_c(x0) > semantic_c(x-)`，并把二分类分数的变化作为较弱的辅助约束。只在干预效应最可靠的少量片段上使用该损失，不覆盖整段异常视频。

这个目标提供“证据责任”，并不提供绝对时间伪标签，所以不会重复上一轮 40% 高 prior 的错误。

### 4.5 阶段 D：渐进解冻是必要的，但按功能统一

完整冻结 baseline 已被多轮实验否定。建议：

1. 先冻结 baseline，仅训练稀疏神经元缩放和 512 维轻量路由器，检查模块是否形成有效反事实；
2. 再解冻每个 baseline 最靠近输出的时序建模块，使其学会使用新证据；
3. 最后仅在验证指标仍上升时，以更小学习率解冻语义投影或分类头。

三个 baseline 解冻的具体层名可以不同，但功能范围必须相同：都是“最后一个时序决策块”，并保留作者原始模型选择、学习率策略和评测方式。通用性应定义为同一接口、同一目标和同一解冻原则，而不是强求不同网络解冻同名参数。

原作者损失必须保持主目标。反事实责任损失若与原损失梯度冲突，可使用 PCGrad 或投影约束，避免辅助解释目标破坏原检测能力。

## 5. 为什么它比已有尝试更可能提升

| 旧方案 | 根本问题 | CNCR 的变化 |
|---|---|---|
| 拼接选中 hidden dimensions | baseline 可忽略新增维度；缺少功能约束 | 直接改变原 512 维证据，并要求输出产生可验证变化 |
| 简单残差注入 | 不知道残差应增强哪一类概念 | 文本概念条件化，每类对应稀疏通路 |
| 神经元 prior + BCE | 将弱定位器错误当作密集真值 | 只约束同一片段干预前后的相对变化 |
| baseline 分数选神经元 | 复制 baseline 偏差和性能上限 | 探测只依赖 CLIP、文本、视频标签和干预效应 |
| 完全冻结 baseline | 强 baseline 不会改变决策边界来使用新证据 | 渐进解冻最后时序决策块 |
| 全局“异常神经元” | 多类别混合，概念熵高 | 类别专属组 + 跨类别共享组分开建模 |

它利用视觉文本对齐的方式也更实质：文本不只生成 prompt 或相似度，而是定义“抑制哪些内部单元后，哪个语义输出应该下降”的可检验反事实。

## 6. 单卡 4090 的开销

推荐先只用最后一层 768 维 hidden states：

- CLIP 图像编码：零新增开销，复用现有 hidden manifest；
- 神经元参数：每类约 32–64 个维度，训练的缩放/偏置通常只有数千参数；
- 路由器：`768 -> 128 -> 512` 的低秩残差约 16 万参数以内，也可进一步缩小；
- 训练前向：反事实视图会增加 baseline 前向开销。可只对一个稀疏片段子集计算 `x+ / x-`，预计训练开销约为原来的 1.3–1.8 倍，而非三倍；
- 推理：只保留 `x+` 路径，增加一次很小的特征路由，远低于时序 backbone 开销。

如果最后一层的因果效应不足，再考虑中间关键层。但直接修改中间层后要精确经过后续 Transformer，需要重新跑部分 CLIP，4090 成本明显增大，所以不应作为第一版正式方案。

## 7. 在正式训练前必须通过的成败门槛

不能直接跑 10 个 epoch 再看 AUC。先做三项低成本验证：

1. **随机对照**：目标神经元组的抑制效应至少显著大于同规模随机组，并在多次随机种子下稳定。
2. **概念专属性**：抑制类别 `c` 后，`c` 文本 logit 的下降应显著大于无关类别；若所有类别一起下降，探测到的只是通用视觉能量。
3. **正常不变性**：正常视频的异常 logit 不应因增强通路普遍升高；否则模块仍在制造全局假阳性。

若三项中任一项失败，说明当前 hidden 层中没有可被可靠调用的异常通路，不应继续联合训练。若通过，再按以下顺序做 DSANet/UCF 消融：

1. 原作者权重复现；
2. 随机神经元路由；
3. 探测神经元路由、baseline 冻结；
4. 探测神经元路由 + 最后时序块；
5. 去掉反事实损失；
6. 去掉类别专属组；
7. 完整 CNCR。

只有第 7 项同时超过作者权重、随机神经元和“无反事实”版本，才能说明提升来自神经元责任机制，而非多参数或额外训练。

## 8. 风险与审稿人可能的质疑

### 8.1 “一个维度就是一个概念神经元”并不严格成立

CLIP 神经元可能多义，中间层还有组合和二阶效应。因此论文应使用“功能单元/稀疏通路”，并用组消融、随机对照、类别专属性和跨视频稳定性支撑解释，避免过度宣称单维语义。

### 8.2 干预成功不必然等于定位正确

[激活修补研究](https://arxiv.org/abs/2311.17030) 指出，使输出按预期变化的子空间不一定就是原模型真实使用的因果位置。为降低该风险，应同时要求：原始激活相关、增强/抑制方向对称、随机组无效、不同视频稳定、对无关概念影响小，而不是只展示一次 ablation。

### 8.3 显著提升不能由方法叙事保证

前一轮实验表明异常知识存在，但没有证明它足以超过强 baseline。CNCR 的价值在于把最关键的不确定性提前变成可测量门槛：如果目标通路的反事实效应不强，就尽早停止；如果效应强但联合训练无提升，则问题在 baseline 如何使用证据，而不是继续改探测分数。

## 9. 推荐的论文主线

论文不要把贡献写成“额外加入神经元特征”。更清晰的逻辑是：

1. 视频级标签和片段级预测之间存在证据责任缺口；
2. 现有方法分别改善正常参照、时间尺度和异常定义，但仍允许模型从整体 CLIP 特征中的偶然共现通路完成 MIL；
3. 预训练视觉语言模型的异常知识可能稀疏分布在内部功能通路中；
4. 提出一个不依赖 baseline 分数的概念条件通路发现方法；
5. 通过反事实增强/抑制给出内部证据监督，而非生成绝对伪标签；
6. 以统一 512 维接口和功能一致的渐进解冻适配三种 baseline；
7. 通过随机通路、类别错配、正常不变性和跨 baseline 迁移证明解释性与通用性。

一句话版本：

> 现有视觉语言 WSVAD 告诉模型“与什么比较、在何种时间尺度比较、按什么定义比较”，而 CNCR 进一步约束“必须依据哪些内部视觉证据作出比较”。

## 10. 最终判断

该方向比继续做拼接、残差或神经元伪标签更有希望，因为它提供的是三个 baseline 都缺少的新监督维度，而不是另一个性能较弱的异常评分器；它也更符合沈飞相关工作的完整范式：定位潜在知识、进行干预验证、再做稀疏定向唤醒。

但建议把下一步定位为“先验证反事实通路是否成立”，而不是直接承诺显著涨点。最值得实现的最小版本是：最后一层类别神经元组、均值抑制/小幅增强、文本 logit 反事实排序、正常不变性、DSANet 最后时序块渐进解冻。该版本可以最大限度复用现有产物，也最适合单卡 4090 快速判断路线是否成立。
