# DSANet / UCF CACC 实验结果

实验日期：2026-08-25。

## 结论

CACC 验证了全层 CLS 中存在不依赖 baseline 分数的补充异常语义，但当前“正常偏离 × 异常语义”的乘积门控没有提高 DSANet。按作者的帧级 AUC 选模规则，正式最佳模型回退到作者权重。

| 模型或训练点 | 已处理样本 | 帧级 AUC | 帧级 AP |
|---|---:|---:|---:|
| 作者 DSANet / 正式最佳模型 | 0 | 0.894446 | 0.374196 |
| CACC + 分类头 | 1280 | 0.894351 | 0.372342 |
| CACC + 分类头 | 2560 | 0.894265 | 0.370595 |
| CACC + 分类头 | 3840 | 0.894159 | 0.371388 |
| CACC + 分类头 | 5120 | 0.894252 | 0.371943 |
| CACC + 分类头 | 6400 | 0.894114 | 0.369657 |
| CACC + 分类头（诊断 checkpoint） | 7680 | 0.893904 | 0.367869 |

六个固定样本验证点都没有超过作者模型，因此在进入时序模块和 DNP 解冻前提前停止，避免重复此前“解冻越深、定位越差”的实验。

## 运行与开销

- 16100 条训练 crop、290 条测试 crop 全部匹配 hidden states，没有缺失视频。
- 正常统计使用 800 个正常训练视频、123681 个 snippet。
- 原始 `[T,12,768]` hidden states 从 `../vad_data` 直接读取，没有复制一份 9216 维特征。
- CACC 主体参数 623682，语义锚点参数 8704；CLIP 可训练参数为 0。
- 训练初始残差严格为 0，首次验证精确复现作者指标。
- 测试 hidden states 使用进程内 float16 缓存；第一次构建约 1 分钟，后续完整验证约 9 秒。

## 诊断 checkpoint 的分解结果

7680 个训练样本的 checkpoint 得到：

| 输出 | 帧级 AUC | 帧级 AP |
|---|---:|---:|
| 作者 DSANet | 0.894446 | 0.374196 |
| 完整 CACC + 微调分类头 | 0.893904 | 0.367869 |
| 关闭 CACC 残差，仅保留微调分类头 | 0.893902 | 0.367867 |
| CACC 乘积门控 | 0.789317 | 0.196802 |
| CACC 正常偏离分支 | 0.744041 | 0.152988 |
| CACC 异常语义分支 | 0.781939 | 0.205104 |

完整模型和关闭残差后的 AUC 只差约 `1.3e-6`。因此本轮性能下降来自分类头微调，而不是 CACC 对输入特征造成了破坏。CACC 学到的实际残差尺度只有 0.000638，尚未形成能影响 baseline 的功能通路。

12 层平均权重都约为 `1/12`，最高层与最低层只相差约 0.0012。这说明当前弱监督目标没有学出可信的层选择，不能把任意一层解释为异常责任层。

## 后验互补性检查

为了判断 CACC 是否完全没有补充信息，额外扫描了作者分数与三个独立分支的线性权重。该扫描使用测试标注，只用于诊断，不能作为正式结果：

- 乘积门控和正常偏离分支的最优权重都是 0，即它们只会降低作者 AUC。
- 异常语义分支在 1% 权重时达到 AUC 0.894776、AP 0.388721。

这项结果不能用于论文报表，因为权重是在测试集后验选择的；但它提供了清晰方向：跨层异常语义与 DSANet 有少量互补性，正常偏离乘法门控会把这部分信息破坏掉。

## 对方法假设的修正

当前实验否定了两个假设：

1. 对标准化 CLS 做低秩投影后，其幅值可以直接充当可靠的正常偏离；
2. 结构偏离和异常语义相乘会比语义本身更适合时序定位。

下一版不应继续调学习率或扩大解冻范围。应先在 baseline 外独立训练并冻结跨层语义子空间，使用训练集内部验证选择层和融合强度；正常分支改为“对正常时间上下文的预测误差或原型距离”，而不是低秩特征幅值。只有独立分支在未参与训练的视频上通过定位门槛后，才允许以固定的小尺度进入 baseline。这样既保留本次发现的语义互补性，也防止分类头微调掩盖模块本身的作用。
