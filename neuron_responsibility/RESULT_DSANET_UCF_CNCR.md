# DSANet / UCF-Crime CNCR 实验结果

## 结论

实验日期：2026-08-24。概念条件神经元通路通过全部因果门控，说明探测到的通路真实影响目标文本概念；但路由没有带来有效检测增益。最佳 checkpoint 相对作者仅提高 0.000192 AUC，并且同一 checkpoint 去掉推理路由后反而略高，证明微小增益来自最后时序块的再优化，而不是神经元增强。

| 模型 | AUC | AP | 相对作者 AUC |
|---|---:|---:|---:|
| 作者 DSANet | 0.894446 | 0.374196 | - |
| 初始神经元路由 | 0.892956 | 0.368147 | -0.001491 |
| CNCR 最佳 checkpoint | 0.894638 | 0.368583 | +0.000192 |
| 同一 checkpoint，关闭路由 | 0.894642 | 0.369542 | +0.000195 |

推理路由的净贡献：AUC -0.000003，AP -0.000959。因此不能将该结果表述为神经元方法提高了 DSANet。

## 神经元通路探测是否成立

- 13 个 UCF 异常类别各选 32 维，去重后共 272 个最后层神经元。
- hidden state 经过同一 `ln_post + visual.proj` 后，与作者 512 维特征平均余弦为 0.948796。
- 选中通路的目标概念干预效应均值为 0.026072；随机维度为 0.000676，前者约为后者 38.6 倍。
- 非目标概念绝对变化为 0.004985，目标效应约为其 5.2 倍。
- 投影、随机对照、正向效应和概念专属性四项门控全部通过。

所以本轮失败不在“有没有探测到功能通路”，而在“推理时增强这些通路是否改善异常定位”。答案是否定的。

## 渐进解冻结果

作者从头训练的 `7e-5` 用于强权重局部适配时，解冻后 5 个 batch 即从约 0.8930 降到 0.8835，后续在 0.883–0.891 间振荡。该运行已停止并保留日志。

将最后时序块学习率降为 `1e-6` 后，AUC 平稳上升：

| 已处理样本 | AUC |
|---:|---:|
| 16,640 | 0.893159 |
| 19,200 | 0.893745 |
| 23,040 | 0.894273 |
| 26,880 | 0.894606 |
| 30,720 | **0.894638** |
| 34,560 | 0.894405 |

作者式 AUC 选模正确保存了 sample 30,720 的峰值。随后连续下降，说明扩大训练轮数不能解决方法瓶颈。

## 为什么仍然没有显著提升

1. 正常 snippet 的平均路由门为 0.2316，异常视频 snippet 为 0.2727，区分过小。路由仍会改变大量正常片段。
2. 概念干预证明“这些维度影响文本相似度”，但没有证明增强文本相似度等价于提高异常时间定位。
3. AUC 略升而 AP 明显下降，说明方法只轻微调整了全局排序，却增加了高分假阳性。
4. 关闭路由后的训练模型最好，表明当前有效部分是反事实损失对时序块的训练期正则化，不是推理特征增强。

## 下一步应如何升级

不再在推理时增强 CLIP 特征。将神经元干预改为纯训练期的“证据筛选器”：

1. 正式推理始终使用作者原始 512 维特征，保证不制造正常片段漂移。
2. 在异常视频内部，只把反事实目标效应最高的极少量 snippet 作为候选集合，不生成绝对伪标签。
3. 作者 MIL 仍负责候选集合内部的难例排序；神经元只限制模型不能选择缺乏对应概念证据的片段。
4. 正常视频只做干预不变性，异常候选比例从 5% 开始，并增加每视频上限。
5. 以“训练后关闭神经元模块仍有提升”作为预期设计，而不是把关闭路由当作失败消融。

这一升级将神经元的角色从“附加异常特征”改为“弱监督证据约束”，更符合当前实验揭示的有效机制。
