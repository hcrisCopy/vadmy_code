# DSANet / UCF 文本神经元责任实验结果

## 结论

实验日期：2026-08-24。文本神经元探测本身有效，但把 64 维责任压成一个绝对异常 prior，再用 BCE 推动 DSANet 最后时序块，无提升。

| 项目 | AUC | AP |
|---|---:|---:|
| 作者 DSANet | 0.894446 | 0.374196 |
| 文本神经元 prior | 0.733183 | 0.154014 |
| 随机 64 维对照 | 0.671742 | 0.123436 |
| 新方法最佳 checkpoint | 0.894420 | 0.373876 |

新方法相对作者权重：AUC -0.000026，AP -0.000320。最佳模型出现在训练 1280 个样本后；继续训练时 AUC 单调下降，最终约为 0.89220。

## 探测是否成立

- 第 12 层 hidden 经同一 CLIP `ln_post + visual.proj` 后，与现有 512 维特征平均余弦为 0.948796，5% 分位为 0.911053。
- 选中神经元比固定随机对照高 0.061442 AUC。
- 选中神经元跨 4 折稳定性均值为 1.0。
- prior 与 DSANet 分数 Pearson 相关系数为 0.611384，确实提供不同信号。
- 选中神经元的概念熵为 0.919587，说明多数维度仍是跨异常类别共享的宽泛方向，而不是清晰的类别专属神经元。

所以失败点不在“有没有探测到信号”，而在“如何把信号交给 baseline”。

## 为什么训练下降

训练集异常视频中，40.39% 的 snippet prior 大于等于 0.8，而小于等于 0.2 的比例只有 0.004%。绝对阈值把大量异常视频背景当成正片段，实际使用的监督覆盖率达到约 72.32%。这会把一个 AUC 只有 0.733 的弱定位器当成密集伪标签，噪声远大于其有效增量。

直接排序融合也把 AUC 降到 0.837364，进一步说明 prior 不适合充当第二个预测头。训练损失下降而正式 AUC 持续下降，是伪标签目标和作者 MIL 目标冲突，不是优化没有收敛。

## 下一版应改什么

不再把神经元责任压成单个异常概率。应保留“神经元 × 文本概念”的责任矩阵，并按每个异常类别分别选择低重叠神经元组。训练时：

1. 原始 binary MIL 完全不改，不给 binary logit 绝对伪标签。
2. 在异常视频内部，只用该视频对应文本概念的责任排序，约束 top 片段高于 bottom 片段；排序完全不依赖 baseline 分数。
3. 用概念责任分布监督三个 baseline 都具备的视觉－文本 semantic logits，而不是直接监督二分类分支。
4. 只解冻最后时序块；原始损失和概念排序损失之间使用 PCGrad，冲突时不允许辅助目标破坏作者目标。
5. 新门控需增加：类别神经元组重叠率、概念检索准确率、top/bottom 定位间隔；不能只看全局 prior AUC。

这一方向同时利用了三种 baseline 的真正共同点：输入是同一 CLIP 视觉空间、内部有时序建模、输出同时包含二分类和文本语义相似度。
