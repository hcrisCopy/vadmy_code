# TCNP / DSANet / UCF-Crime 实验结果

## 结论

TCNP 的训练集质量门控通过，但 DSANet head-only pilot 没有超过作者模型。固定选模规则最终保留作者 checkpoint，正式 AUC/AP 增益均为 0。这个结果不支持继续扩大解冻范围，也不支持直接把当前 TCNP 用作伪帧标签。

## 探针与候选审计

神经元来自 CLIP ViT-B/16 第 8、12 个 Transformer block（代码中的 zero-based layer 7、11），共复用 1254 个“层—原始 CLS 维度”坐标；可训练探针只有 16,380 个参数，不依赖任何 baseline 异常分数。

| 指标 | 原型硬交集（否决） | 语义主信号（采用） |
|---|---:|---:|
| 训练留出正常片段误报率 | 0.30% | 0.81% |
| 训练留出异常视频覆盖率 | 22.78% | 63.92% |
| 已覆盖视频类别准确率 | 47.22% | 57.43% |
| 固定测试帧 AUC | 69.97% | 75.10% |
| 固定测试候选 precision | 24.94% | 17.17% |
| 固定测试候选 recall | 3.89% | 38.81% |

正常原型距离在训练留出集 2% FPR 下只能覆盖 46.84% 的异常视频，而文本神经元语义能覆盖 72.15%；强制二者取交集因此没有依据。最终把正常原型和跨层一致性保留为审计通道，语义作为主定位信号。质量门槛使用训练视频划分，测试帧标注未参与训练、阈值校准或门控。

## 失败原因

1. 文本条件神经元比原型交集明显更有召回，但测试候选 precision 仍只有 17.17%，不足以作为可靠片段监督。
2. 探针测试 AUC 75.10% 远低于 DSANet 89.44%，把它作为硬 top/bottom 排序教师必然限制甚至扰动强 baseline。
3. 训练留出视频级覆盖门槛能排除完全失效的候选，却不能保证帧级边界精度；视频级弱标签仍无法证明某个高响应片段就是异常片段。
4. 当前回路每类都达到 `k-grid` 上限 128，两个选中层的 union 达 1254，说明所谓“最小充分回路”实际并不稀疏。单个维度语义过于分散，解释性成立但定位能力不足。

因此，下一步若仍坚持 hidden-state 可解释性，不能继续把低于 baseline 的独立探针当教师。更合理的突破点是让神经元只提供“类别/概念约束”，而由 baseline 自己的高分片段与跨裁剪/时间增强一致性负责定位；神经元约束应作为软正则而非替代定位分数。该方向会再次依赖 baseline 的训练信号，但不再用 baseline 分数做神经元发现，需要在论文中明确区分。
