# TRACE-Raw：DSANet / UCF-Crime 实验结果

## 结论

本轮没有超过 DSANet。作者权重精确复现 `89.4446` frame AUC；TRACE 适配的末段结果为 `89.3898`，下降 `0.0549` 个百分点。按 DSANet 的 frame AUC 规则选择模型后，best checkpoint 保留作者起点，因此正式评测的增益为 `0.0000`，没有把退化模型当成最终结果。

## 正式指标

| 输出 | Frame AUC | Frame AP |
|---|---:|---:|
| 作者 DSANet | 89.4446 | 37.4196 |
| TRACE best | 89.4446 | 37.4196 |
| 训练末段 TRACE | 89.3898 | 36.8487 |
| 神经元语义证据 | 76.0479 | 16.5366 |
| 邻域时间创新 | 57.8496 | 11.6127 |
| 两类证据融合 | 74.0734 | 17.6590 |

语义探针从随机初始化的 `49.44` AUC 提高到 `76.05`，说明选中的原始维度含异常判别信息；但时间创新只有 `57.85`，加入后把语义 AUC 从 `76.05` 降到 `74.07`。因此当前时间证据不是有效的互补教师。

## 失败根因

使用测试标注做了一次固定的事后诊断，只用于解释失败，不用于调参或报告主结果：

| 候选集合 | 选中 snippets | Precision | Recall |
|---|---:|---:|---:|
| 语义高阈值 | 20,852 | 16.05% | 61.98% |
| 时间高阈值 | 2,163 | 24.87% | 9.96% |
| 语义与时间交集种子 | 1,086 | 39.23% | 7.89% |
| DSANet 同数量 top snippets（诊断参照） | 1,086 | 49.17% | 9.89% |

交集把 precision 提高了，但仍低于 DSANet 自身，而且只召回约 8% 的异常 snippets。训练日志中，同样大小的 batch 经事件扩张后可产生数百到四千多个 positives，说明固定的全局 normal quantile 没有处理视频间尺度差异；`semantic OR temporal` 的扩张支持又会把低质量种子放大。弱教师对强学生做 pseudo supervision，结果只能缓慢破坏原有排序。

## 下一版必须改变什么

不能继续围绕学习率或解冻深度微调。下一版应先提高独立教师质量，达到门槛后才允许训练 baseline：

1. 删除当前的邻域绝对差时间教师。它主要响应镜头切换和相机运动。替换为只在正常视频训练、带遮挡中心预测的多尺度 temporal predictor，并按每视频正常上下文做校准。
2. 当前语义探针本质仍是 binary MIL，没有真正利用三套 baseline 共有的视觉—文本对齐。下一版应使用固定 CLIP 类别/属性文本原型训练 class-aware embedding probe；神经元责任由类别文本方向上的稀疏权重定义，而不是只有一个异常 logit。
3. 正常视频的所有 snippets 都是确定负样本，应直接施加 all-normal suppression；异常视频只使用跨类别文本、normal predictor 和时间持续性三者一致的少量正种子。
4. 在种子 precision 未达到门槛前禁止 event growth；扩张边必须同时满足类别语义一致和时间预测支持，不能再使用 OR。
5. baseline 训练前先做固定候选审计。若独立种子没有明显优于等数量参照，停止该轮，而不是让弱教师继续蒸馏。

本轮最有价值的结果不是 `0` 增益，而是明确验证了：动态选层和原始神经元探针能提取信息，但“binary MIL + 邻域变化 + OR 扩张”不足以成为强 baseline 的片段教师。下一次升级必须落实视觉—文本类别责任和学习式正常时序预测这两个结构变化。
