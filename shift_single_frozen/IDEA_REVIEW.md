# 方案审查

## 这条实验回答什么

它是最干净的因果对照：不改正负样本规则、不增加第二注入点、不解冻任何baseline参数，只检验“baseline专属探测到的神经元能否通过一次残差改善原模型”。

## Idea质量

| 维度 | 评价 |
|---|---|
| 控制变量 | 高。相对原Shift只明确约束baseline专属selection和全冻结。 |
| 通用性 | 高。同一残差接口适配三个baseline和两个数据集。 |
| 可解释性 | 中高。可以追溯分数尾部、层/维度选择、门控和残差能量。 |
| 开销 | 低。复用hidden states，只训练约一个MLP。 |
| 创新性 | 中低。更适合作为可靠基线和消融，不足以单独支撑完整方法。 |
| 显著提升把握 | 偏低。冻结决策边界会限制残差信息被baseline利用。 |

## 必须怎样解释结果

- 指标提升且残差RMS非零：baseline专属神经元证据能够被固定模型利用。
- 指标不变且残差接近零：弱监督目标没有驱动残差工作。
- 残差明显但指标不升：探测方向或固定决策边界不合适。
- 不同baseline选中神经元差异大：证明selection确实不应跨baseline复用。

本方案不宣称解决CLIP文本语义纠缠，也不宣称改善视觉文本联合空间；它只是一条严格、低开销的单残差冻结对照。
